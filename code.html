Splash / Loading Anim Breakdown


Observation

This project documents observations made while examining the works.studio website using the browser's Inspect Element tool. For each feature studied, an observation is recorded, followed by a likely explanation, the evidence supporting it, and anything left unconfirmed. The site examined is works.studio, a creative agency website. Three features are covered here: the loading animation, the About navigation behavior, and the project card hover previews.


Mechanism

A yellow overlay sits on top of the page while it loads. Once the page is ready, the overlay fades out while the headline text fades in at roughly the same time.


Evidence

The site's code contains an element labeled as a loader, with its background color set to fade to fully transparent. It is also marked as hidden from screen readers once complete, indicating the site treats it as finished at that point. Whether the yellow screen's duration depends on how long the page actually takes to load, or runs for a fixed amount of time regardless, has not been confirmed. This could be tested by slowing the network connection intentionally and observing whether the loading screen lasts longer.

The site examined is works.studio, a creative agency website. Three features are covered here: the loading animation, the About navigation behavior, and the project card hover previews.


Mechanism

Clicking does more than open the panel — it also marks the About link as currently active, similar to how a selected tab stays highlighted. This marking is what keeps the color in place.


Evidence

Comparing the code before and after the click shows the link gaining an additional label afterward, along with a rule that overrides its default grey color. Whether clicking changes the browser's URL, or is handled entirely within the same page, has not been confirmed.

Project Cards / Previews


Observation

Hovering over a project image in the grid causes it to visually stand out from the others.


Mechanism

Each project card is an individual item in a list. When the cursor enters one, it is marked as "highlighted" — the rest are likely styled to recede by comparison.


Evidence

Inspecting a card while hovering over it shows the word "highlighted" added directly to that card's code, and only that one. The exact style change tied to "highlighted" has not been confirmed — whether it dims the other cards, enlarges the hovered one, or both. Reviewing the associated style rule directly would settle this.
